The agent fixture emitted a tool call on all three trials. ## Errors, recovery, and scope

- Secure-only stock polling caught a briefly available RTX 3090; the first create attempt lost a stock race, and the next Secure create succeeded. No Community pod was used.
- The image omitted CUDA from `PATH`; the workspace environment added `/usr/local/cuda-13.0/bin`. A setup script initially failed to locate `strata` by process name, before sending a benchmark request; it was corrected to match the exact server command.
- Direct SSH archive transfer ran at about 12–14 MB/s. After the timed runs, the pinned Hugging Face revision was pulled directly with segmented range downloads (about 30 MiB/s for `ple-fp8.gguf`). The downloaded snapshot passed SHA-256 comparison against the pod's inventory. Interrupted transfer fragments and the earlier 125 CUDA compiler temporary files that disappeared from the pod before its final inventory are preserved in the local archive; the latter have their own checksum list.
- Optional 32 GiB RAM cap, Qwen3.8-27B llama.cpp comparison, and Hermes tool-call smoke test were not run. These are outside the required primary benchmark; the synthetic agent fixture was run and reviewed as above.
- The older `runpodctl` teardown command could not resolve its REST v1 hostname at the end of the run. The supported REST v2 `DELETE /v2/pods/{id}` returned HTTP 204; a subsequent GET returned 404. The sanitized receipt and provider billing record are in the archive.

## Reproduction and evidence

The published [article](https://majorminor.xyz/research/cuda-recipes-006) includes the launch command and benchmark settings. Follow the [pinned Linux build instructions](https://github.com/Edge0-AI/Edge0/blob/v0.2.0/edge0-strata/EDGE0.md#build-linux-nvidia), then build Edge0 Infer with its CPU preset. Download the pinned model snapshot listed above and confirm it with `edge0-infer inspect --model /workspace/models/Edge0-145B-q3k --json`.

Start a fresh server before each request. Repeat each of the four workloads three times against the loopback endpoint:

```bash
build/cpu/bin/edge0-infer serve --model /workspace/models/Edge0-145B-q3k --device cuda:0
# In a second terminal, from this study directory:
python3 scripts/record_trial.py results/prompts/chat_decode.json --trial-id chat_decode-r1 --output-dir /tmp/edge0-chat-decode-r1
```

Use [trials.jsonl](../receipts/trials.jsonl) to check the reported rates and [benchmark_summary.json](../receipts/benchmark_summary.json) for memory and workload summaries. The [frozen requests](prompts/) include hashes. The complete pod archive remains in private local storage.
